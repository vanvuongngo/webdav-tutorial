Hier findest du die Anleitung zur Installation von [Radicale](/reference/radicale) ein OpenSource [WebDAV](http://webdav.org/) service für unterschiedlichen Linux-Distributionen.

Es läuft unter [Alpine Linux](https://alpinelinux.org/), diese Linux-Distribution ist extrem schlank und bietet einen erhöhten Grad an Sicherheit.

Auch [Debian](https://debian.org/) basierte Distributionen werden unterstützt. Diese Linux-Distribution bietet eine Bandbreite von Anwendung: von hohe Stabilitätsanforderung ([Debian](https://debian.org/)) bis die Anwender benutzungsfreundliche UI mit Windows look-and-feel  ([Mint](https://linuxmint.com/)).

Für Anwender die vorher MacOS genutzt haben und eine stabile Distribution suchen, für die wäre [Fedora Workstation](https://fedoraproject.org/workstation/) Linux eine Option.

<Steps>

1. Installiere Radicale

    <Tabs syncKey="distributions">
        <TabItem label="Alpine">
            <Code
                code="sudo apk add --update --no-cache radicale apache2-utils openssl nano"
                lang="sh"
            />
        </TabItem>
        <TabItem label="Debian/ Mint/ Ubuntu"
            ><Code
                code="sudo apt-get update
                sudo apt-get install radicale"
                lang="sh"
            />
        </TabItem>
        <TabItem label="Fedora"
            ><Code
                code="sudo dnf update
                sudo dnf install radicale3.noarch"
                lang="sh"
            />
        </TabItem>
    </Tabs>

2. Konfiguriere Radicale

    ```sh
    sudo nano /etc/radicale/config
    ```

    <Code
        code="[server]
hosts = 127.0.0.1:5232

[auth]
type = htpasswd"
        title="/etc/radicale/config"
        lang="ini"
    />
    `hosts = 127.0.0.1:5232` bietet die maximale Sicherheit, da [Radicale](/reference/radicale) nur auf den eigenen PC erreichbar ist.

    Achtung - nicht empfehlswert und möglich: Man kann `hosts = 0.0.0.0:5232` setzen, dann ist Radicale auch von anderen Rechner/ Smartphone zu erreichen.
    Da es um eine unverschlüsselt HTTP Verbindung handelt, ist die Netzwerübertragung nicht gesichert und wenn man einen Notebook mit einen Hotspot verbindet, ist die Kommunikation abhörbar.
    Nur zu Hause zu empfehlen und auf einen Server/ Mini-PC daheim.

    Für eine empfohlene verschlüsselte HTTPS Verbindung, siehe Kapitel [Verschlüsselte HTTPS Verbindung](http://localhost:4321/webdav-tutorial/guides/secure/).

3. Zugänge einrichten

    Beliebige Anzahl von Benutzern anlegen (wiederholen):
    ```sh
    sudo htpasswd -B /etc/radicale/users <USER-NAME>
    ```
    `<USER-NAME>` mit deinen Benutzernamen einsetzen

4. Radicale Dienst autostart und starten

    Damit [Radicale](/reference/radicale) bei einen Neustart des PC automatisch startet, muss man wie folgt einrichten:

    <Tabs syncKey="distributions">
        <TabItem label="Alpine">
            schalte Autostart ein
            <Code
                code="sudo rc-update add radicale default"
                lang="sh"
            />
            starte [Radicale](/reference/radicale)
            <Code
                code="sudo rc-service radicale start"
                lang="sh"
            />
        </TabItem>
        <TabItem label="Debian/ Mint/ Ubuntu">
            ACHTUNG: noch nicht getestet

            Systemd Konfiguration neu laden
            <Code
                code="sudo systemctl daemon-reload"
                lang="sh"
            />
            schalte Autostart ein
            <Code
                code="sudo systemctl enable radicale"
                lang="sh"
            />
            starte [Radicale](/reference/radicale)
            <Code
                code="sudo systemctl start radicale"
                lang="sh"
            />
            Überprüfe Status
            <Code
                code="sudo systemctl status radicale"
                lang="sh"
            />
        </TabItem>
        <TabItem label="Fedora">
            ACHTUNG: noch nicht getestet

            <Code
                code="sudo adduser radicale"
                lang="sh"
            />
            <Code
                code="mkdir -p /var/lib/radicale/collections"
                lang="sh"
            />
            <Code
                code="chown -R radicale:radicale /var/lib/radicale"
                lang="sh"
            />
            <Code
                code="nano /etc/systemd/system/radicale.service"
                lang="sh"
            />
            <Code
                code="[Unit]
Description=A simple CalDAV (calendar) and CardDAV (contact) server
After=network.target
Requires=network.target

[Service]
ExecStart=/usr/bin/env python3 -m radicale
Restart=on-failure
User=radicale
Group=radicale
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
PrivateDevices=true
ProtectKernelTunables=true
ProtectKernelModules=true
ProtectControlGroups=true
NoNewPrivileges=true
ReadWritePaths=/var/lib/radicale/collections

[Install]
WantedBy=multi-user.target"
                lang="sh"
            />
            Dienst aktivieren und starten
            <Code
                code="sudo systemctl daemon-reload
sudo systemctl enable radicale
sudo systemctl start radicale"
                lang="sh"
            />
            Überprüfe Status
            <Code
                code="sudo systemctl status radicale"
                lang="sh"
            />
        </TabItem>
    </Tabs>
