Die Open Security und Networking Platform: [Pangolin](https://pangolin.net/)

Dokumentation: https://docs.pangolin.net

### Voraussetzungen

- ein cloud VPS linux server

- eine domain (z.B. meineseite.ch)

- eine E-Mail Adresse für [Let's Encrypt](https://letsencrypt.org/)

- offen erreichbare TCP ports `80` und `443` zum VPS

- offene UDP ports `51820` und `21820` zum VPS für Newt


## VPS Anforderungen

Hilfe für die Auswahl eines VPS: https://docs.pangolin.net/self-host/choosing-a-vps

- CPU: 1 vCPU

- RAM: 1 GB mit swap space
